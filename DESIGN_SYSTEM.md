# Design System - Sumi-style Minimalist

A sophisticated, paper-textured design system with dark backgrounds and warm accents.

## Typography

### Fonts
- **Primary**: IBM Plex Mono, JetBrains Mono, SF Mono, Monaco, Cascadia Code
- **Weight**: 400 (regular) for body, 600 (semibold) for headings
- **Size Scale**:
  - xs: 11px
  - sm: 12px
  - base: 13px
  - md: 14px
  - lg: 15px
  - xl: 17px
  - 2xl: 19px

### Line Height
- Body: 1.5
- Headings: 1.2
- Code: 1.4

### Letter Spacing
- Body: -0.01em (tight)
- Headings: -0.02em (tighter)
- Uppercase: 0.03em (slightly loose)

## Colors

### Sumi-style Palette
- Page Background: `#050608` (Ink Black)
- Card Background: `#F5F2EC` (Paper White - warm off-white)
- Text: `#2D2D2D` (Charcoal)
- Text Muted: `#6B6B6B` (Medium gray)
- Border: `#D4C5B9` (Warm gray)
- Accent: `#C1121F` (Deep Red)
- Accent Hover: `#A00F1A` (Darker red)
- Code BG: `#E8E5DD` (Slightly darker paper)
- Code Border: `#D4C5B9` (Warm gray)

## Spacing

Compact scale for technical density:
- 2xs: 0.125rem (2px)
- xs: 0.25rem (4px)
- sm: 0.375rem (6px)
- md: 0.5rem (8px)
- base: 0.75rem (12px)
- lg: 1rem (16px)
- xl: 1.5rem (24px)
- 2xl: 2rem (32px)

## Layout

- **Max Width**: 760px (compact)
- **Padding**: 12px (small)
- **Border Width**: 1px (thin lines)
- **Border Radius**: 0px (sharp edges)

## Components

### Headers
- Border: 1px solid black (sharp)
- Transform: uppercase
- Weight: 600

### Links
- Color: accent (burnt ember)
- Underline: on hover only
- Weight: 400 (thin)

### Buttons/Cards
- Border: 1px solid border-color
- Padding: 8px 12px (compact)
- Hover: border-color changes to accent

### Images
- Border: 1px solid border-color
- Filter: grayscale(100%)
- Hover: grayscale(0%)

### Code
- Background: subtle gray
- Border: 1px solid border-color
- Padding: 2px 4px (inline), 8px (block)

## Principles

1. **Sumi Aesthetic**: Ink-black backgrounds with paper-white content cards
2. **Warmth**: Warm grays and paper textures create inviting contrast
3. **Sharp**: No rounded corners, crisp borders
4. **Technical**: Monospace everywhere, compact spacing
5. **Layered**: Dark page → light cards → structured content
6. **Sophisticated**: Deep red accents used sparingly
7. **High Contrast**: Charcoal text on paper-white cards
8. **Minimal Shadows**: Subtle depth without heavy effects
